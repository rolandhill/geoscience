# Set Transparent Colour

![Transparent White](help://../icon/WhiteTransparent.png) **Geoscience > Raster > Transparent White** sets the transparent colour to **white** for all the raster images selected in the Layers panel.

![Transparent Black](help://../icon/BlackTransparent.png) **Geoscience > Raster > Transparent Black** sets the transparent colour to **black** for all the raster images selected in the Layers panel.

To use them, first select all the rasters you wish to process using Ctrl and Shift left clicks, then choose the menu entry or toolbar button. They are ideal for image sets such as EM channels or hyperspectral images.
