# Set Transparent Colour

![Transparent White](help://../icon/WhiteTransparent.png) **Geoscience > Raster > Transparent White** sets the transparent colour to **white** for all the raster images selected in the Layers panel.

![Transparent Black](help://../icon/BlackTransparent.png) **Geoscience > Raster > Transparent Black** sets the transparent colour to **black** for all the raster images selected in the Layers panel.

To use them, select the rasters you want to change in the Layers panel (use Ctrl+click or Shift+click to select several), then choose the menu command or click the toolbar button. They are ideal for sets of images such as EM channels or hyperspectral bands.

> [!NOTE]
> These commands are for RGB images. They set the transparent pixel colour on the **Transparency** tab of each layer's properties, where you can change or remove it later.
